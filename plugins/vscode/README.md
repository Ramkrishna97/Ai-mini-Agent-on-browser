# AI Agent Mini for VS Code

Build with `npm install` and `npm run package`, then use **Extensions → Install from VSIX** on the generated file. Open the **AI Agent Mini** activity-bar view. The extension connects to the existing local app when it is running; otherwise its bundled backend starts headlessly, using Python 3.12+ to prepare dependencies on first launch. **Start** retries the connection. No app folder is needed; `aiAgentMini.appPath` remains an optional override for development. Running the repository's `start.bat` still opens the original web UI.

Select Ollama, a local GGUF file, or LM Studio API and choose a model. The Ollama and LM Studio model lists are queried directly before **Start**; their local API servers must be running to show models at that point. **Load** starts the bundled backend and, for Ollama, starts its server if needed. Set the context size and click **Load in LM Studio** to load the selected model. Optional **Choose skill folder** and **Choose MCP JSON** buttons import local LM Studio-compatible sources; MCP use is opt-in and every tool call remains approval-gated. Choose **Agent** to plan, edit, and run with approval, or **Chat** for answers without tools. The active VS Code workspace and editor path are passed to the same agent used by the web UI. Enter sends; Shift+Enter inserts a line. New chat creates a separate in-memory session, cleared when the backend restarts.
